Wireframe gallery — the primary screen of every module

Mid-fidelity wireframes for the key screen of each module across all ten portals — layout, hierarchy, controls and state, on the SALIS brand system. Every route printed below is a route the app actually serves, checked against the registry.

How to read: each card shows the browser frame, the route, and the screen's blocks — KPIs, tables, forms, charts, maps, chat and mobile card layouts — using the same wireframe kit throughout so density and rhythm are comparable across roles. A card with a DESIGN PROPOSAL · NOT BUILT badge and a dashed frame has no route: the screen was drawn but never shipped, so there is no URL to print.

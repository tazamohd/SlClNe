# Database audit

`db-audit.html` is the source of the published SALIS AUTO Database Audit artifact.

It lives here for one reason. The previous revision of this report was published
only as an artifact, and it marked its own top finding — the frozen drizzle
snapshot chain — as **fixed** while the repair existed in no commit, branch or
worktree. A report nobody can diff against the tree is a report that can say
anything. Keeping the source in the repository means the next revision is a
reviewable change and its claims sit next to the code they describe.

To republish: publish this file to the artifact, keeping the same URL.

## 1. Purpose

This document defines the SALIS AUTO certification framework, including tier requirements, assessment criteria, validity periods, recertification processes, and digital badge issuance. The framework ensures all platform users achieve and maintain a verified level of proficiency.

---

## 2. Certification Tiers

### 2.1 Tier Overview

| Tier   | Minimum Score | Badge Color | Trainer Eligible | Description                         |
|--------|---------------|-------------|------------------|-------------------------------------|
| Bronze | 70%           | Bronze      | No               | Competent user -- meets baseline    |
| Silver | 80%           | Silver      | No               | Proficient user -- above average    |
| Gold   | 90%           | Gold        | Yes              | Expert user -- eligible to train    |

### 2.2 Tier Details

#### Bronze Certification

- **Minimum Assessment Score**: 70% across all course modules
- **Requirements**:
  - Complete all modules in the assigned course
  - Pass the final assessment with 70% or higher
  - Complete all hands-on labs (attendance verified by trainer)
- **Privileges**:
  - Full platform access for the assigned role
  - Listed as "Certified" in the staff directory
  - 12-month validity

#### Silver Certification

- **Minimum Assessment Score**: 80% across all course modules
- **Requirements**:
  - Meet all Bronze requirements
  - Score 80% or higher on the final assessment
  - Complete at least one cross-functional lab (e.g., advisor completes a finance lab)
- **Privileges**:
  - All Bronze privileges
  - Eligible for cross-training in adjacent roles
  - Priority consideration for role advancement
  - 12-month validity

#### Gold Certification

- **Minimum Assessment Score**: 90% across all course modules
- **Requirements**:
  - Meet all Silver requirements
  - Score 90% or higher on the final assessment
  - Complete the Train-the-Trainer module (SA-TRN-012)
  - Pass the trainer qualification assessment
  - Demonstrate bilingual delivery capability (EN/AR)
- **Privileges**:
  - All Silver privileges
  - Eligible to deliver training sessions as a certified trainer
  - Mentor new hires during onboarding
  - Participate in content review and course updates
  - 12-month validity

## 4. Assessment Process

### 4.1 Assessment Structure

| Parameter               | Value                                          |
|-------------------------|------------------------------------------------|
| Format                  | Multiple-choice (4 options per question)       |
| Questions per assessment| 30 (drawn from the Assessment Bank SA-TRN-013)|
| Time limit              | 45 minutes                                     |
| Question randomization  | Yes (order and options randomized per attempt) |
| Maximum attempts        | 3                                              |
| Cooldown between attempts| 48 hours                                      |
| Accommodation           | +50% time for non-native language test takers  |

### 4.2 Scoring Methodology

- Each correct answer scores 1 point
- No negative marking for incorrect answers
- Final score = (correct answers / total questions) x 100%
- The highest score across all attempts determines the certification tier

### 4.3 Assessment Administration

| Method       | Applicable Tracks          | Proctor Required |
|--------------|----------------------------|------------------|
| In-person    | Executive, Operations      | Yes              |
| Online (LMS) | Back-Office, External     | No (honor system)|
| Proctored online | Any (on request)       | Yes (remote)     |

### 4.4 Remediation

If a participant fails to achieve Bronze (70%) after 3 attempts:

1. Mandatory review session with a certified trainer (2 hours)
2. Identify knowledge gaps using the per-domain score breakdown
3. Complete targeted remediation modules for weak domains
4. 7-day waiting period before a new assessment cycle (3 more attempts)
5. If still unsuccessful, escalate to HR Manager and Training Coordinator

## 5. Validity & Recertification

### 5.1 Certification Validity

| Parameter            | Value                        |
|----------------------|------------------------------|
| Initial validity     | 12 months from issue date    |
| Renewal window       | 60 days before expiration    |
| Grace period         | 30 days after expiration     |
| Lapsed certification | Requires full reassessment   |

### 5.2 Recertification Process

| Step | Action                                          | Responsible        |
|------|-------------------------------------------------|--------------------|
| 1    | LMS sends renewal notification (60 days before) | Automated          |
| 2    | Participant completes refresher module (1-2 hr)  | Participant        |
| 3    | Participant takes recertification assessment     | Participant        |
| 4    | Score determines renewed tier                    | Automated          |
| 5    | New certificate issued with updated validity     | LMS                |
| 6    | HR updates the staff certification register      | HR Manager         |

### 5.3 Recertification Triggers

Beyond the annual cycle, recertification may be triggered by:

| Trigger                               | Action Required                       |
|---------------------------------------|---------------------------------------|
| Major platform update (new modules)   | Targeted refresher + assessment       |
| Role change (e.g., advisor to manager)| Complete the new role's course        |
| ZATCA regulation change               | Finance module refresher              |
| SOD policy update                     | Admin/security module refresher       |
| Extended leave (90+ days)             | Refresher assessment upon return      |

### 5.4 Certification Revocation

Certifications may be revoked under the following circumstances:

| Circumstance                          | Action                                |
|---------------------------------------|---------------------------------------|
| Repeated SOD violations               | Immediate revocation; retraining      |
| Security policy breach                | Revocation pending investigation      |
| Employment termination                | Automatic revocation                  |
| Fraud or exam integrity violation     | Permanent ban from certification      |

## 7. Reporting & Analytics

### 7.1 Certification Dashboard

The Training Coordinator and HR Manager have access to a certification dashboard with:

| Metric                          | Description                              |
|---------------------------------|------------------------------------------|
| Overall certification rate      | % of staff with active certification     |
| Tier distribution               | Bronze / Silver / Gold counts            |
| Expiring soon                   | Certifications expiring within 60 days   |
| Lapsed certifications           | Past grace period, requiring reassessment|
| Assessment pass rate by domain  | Identifies systemic knowledge gaps       |
| Average score by role           | Benchmarks per role                      |
| Time to certification           | Average days from enrollment to pass     |

### 7.2 Compliance Reporting

| Report                         | Frequency | Audience           |
|--------------------------------|-----------|--------------------|

| Training completion summary    | Weekly    | Branch Managers    |
| Assessment trend analysis      | Quarterly | Training Coordinator|
| Remediation tracking           | As needed | HR Manager         |

## 8. Governance

### 8.1 Roles and Responsibilities

| Role                  | Responsibility                                           |
|-----------------------|----------------------------------------------------------|
| Training Coordinator  | Program oversight, content review, compliance tracking   |
| HR Manager            | Enrollment management, certification register, reporting |
| Lead Trainer          | Assessment delivery, remediation, content feedback       |
| Super Admin           | LMS configuration, badge issuance, system integration    |
| Owner/CEO             | Program sponsorship, strategic review                    |

### 8.2 Review Cycle

| Activity                        | Frequency  | Owner                |
|---------------------------------|------------|----------------------|
| Assessment question review      | Quarterly  | Training Coordinator |
| Certification tier criteria     | Annually   | SALIS AUTO PMO       |
| Badge design and metadata       | Annually   | Super Admin          |
| Remediation process review      | Semi-annual| HR Manager           |
| Program effectiveness review    | Annually   | Owner/CEO            |

### 8.3 Change Management

Changes to the certification framework require:

1. Written proposal from the Training Coordinator
2. Review by HR Manager and Super Admin
3. Approval by the Owner/CEO
4. 30-day notice to all certified staff before implementation
5. Updated documentation published to the LMS

## 1. Vision Statement

**"The intelligent platform that powers every automotive workshop in Saudi Arabia."**

SALIS AUTO envisions a future where every automotive workshop in the Kingdom,
from the single-bay garage in a Riyadh side street to the 50-bay enterprise
operation on the Eastern Province highway, runs on a single, intelligent
platform that eliminates paperwork, ensures regulatory compliance, and
unlocks data-driven decision-making.

---

## 2. Mission Statement

Digitize automotive workshop operations across Saudi Arabia through a
purpose-built SaaS platform that delivers:

- **ZATCA-native compliance** -- Phase 2 e-invoicing (15% VAT) built into
  every transaction, eliminating manual filing and audit risk
- **AI-powered efficiency** -- Intelligent estimation, predictive inventory,
  and automated workflow routing that reduce cycle times by 40%+
- **Exceptional bilingual UX** -- Arabic-first, RTL-native design with full
  English support, ensuring adoption across all staff literacy levels
- **Multi-tenant scalability** -- A single codebase serving 14 distinct roles
  across 13 operational domains and 191+ screens

## 7. Technology Strategy

### 7.1 Architecture Principles

| Principle               | Implementation                                          |
|-------------------------|---------------------------------------------------------|
| API-first design        | Every feature exposed via versioned REST/GraphQL APIs   |
| Multi-tenant isolation  | Row-level security with tenant context in every query   |
| Event-driven backbone   | Domain events for cross-module communication            |
| Mobile-first UX         | Responsive design with progressive enhancement          |
| Bilingual by default    | i18n keys for all user-facing strings, RTL-native CSS   |

### 7.2 AI Platform Evolution

| Phase     | Capability                        | Business Impact                     |
|-----------|-----------------------------------|-------------------------------------|
| Phase 1   | Rule-based estimation engine      | Consistent pricing, faster quotes   |
| Phase 2   | ML-powered cost prediction        | 15% more accurate estimates         |
| Phase 3   | NLP for service descriptions      | Auto-categorize jobs from AR/EN text|
| Phase 4   | Computer vision for inspections   | Photo-based damage assessment       |
| Phase 5   | Predictive maintenance models     | Proactive service recommendations   |

### 7.3 Infrastructure Strategy

- **Cloud Provider:** AWS Middle East (Bahrain) region for data sovereignty
- **CDN:** CloudFront with Riyadh edge locations for <100ms latency
- **Database:** PostgreSQL with read replicas; Redis for caching
- **CI/CD:** GitHub Actions with automated testing and staging deployments
- **Monitoring:** Datadog APM with custom Saudi business-hours alerting
- **Disaster Recovery:** Cross-region replication with 4-hour RPO, 1-hour RTO

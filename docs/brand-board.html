The rule everything else follows

The colour law

Blue is success, active and progress. Orange is warnings and critical calls to action. There is no third signal colour.

This is the most distinctive thing about the SALIS AUTO interface and the easiest to break. Screens rebuilt from screenshots are how it gets broken — reproduce structure and content, never the source's palette.

Enforced, not advised. A smoke check walks the computed styles of rebuilt screens and fails the build on dominant green or purple. See app/README.md §7.

Never

greenredyellow purplepinkteal

Green and red are the two most common status colours in software. Removing them is a deliberate cost: severity has to be carried by weight, position and wording instead of hue — which also means the interface still works for the colour-blind readers on a workshop floor.

Voice

Precise, accountable, plain, respectful

The reader is a professional under time pressure. Every line below already ships somewhere in the product — this codifies a tone that was consistent but unwritten.

Precise

Name the exact thing. The field, the amount, the id. "That phone is already in use" beats "Duplicate record detected".

Accountable

Say what happened and what the reader can do next. When the system fails, it hands over a request id rather than an apology.

Plain

Short sentences. Contractions are fine. No ceremony, no exclamation marks.

Respectful

Never scold, never congratulate, never explain the reader's own job back to them.

What the mirror actually costs

The layout is not flipped by a second stylesheet. Every offset uses logical properties — margin-inline-start, border-inline-start — so one rule set serves both directions.
Latin runs inside Arabic text carry dir="ltr". Without it the bidi algorithm reorders the digits, and TRK-8802 silently becomes 8802-TRK on a fiscal document.
Currency stays font-mono with comma thousands and two decimals in both directions, so a column of totals aligns whichever way the page reads.
Arabic copy is written for Arabic. Length differences are a layout problem to solve, never a reason to abbreviate the Arabic and not the English.

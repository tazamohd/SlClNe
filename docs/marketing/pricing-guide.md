## 1. Introduction

This document defines the pricing structure for SALIS AUTO, including subscription tiers, add-on modules, implementation fees, and discount policies. All prices are in Saudi Riyals (SAR) and exclude VAT unless stated otherwise. VAT at 15% applies to all fees per ZATCA regulations.

This guide is for internal sales use. Do not share this document directly with prospects. Use it to prepare customer-facing proposals.

## 3. Tier Details

### 3.1 Starter (SAR 999/month)

**Target**: Single-location independent workshops needing core digitization and ZATCA compliance.

| Parameter              | Value                                              |
|------------------------|----------------------------------------------------|
| Monthly Subscription   | SAR 999                                            |
| Annual Subscription    | SAR 10,190 (save SAR 1,798)                        |
| Branches               | 1                                                  |
| Named Users            | Up to 10                                           |
| Storage                | 10 GB (documents, photos, attachments)             |
| Support                | Email support, 24-hour response SLA                |
| SLA                    | 99.5% uptime                                      |
| Data Backup            | Daily, 14-day retention                            |
| Updates                | Included, automatic deployment                     |

**Included modules**: Workshop, Registry, Finance (basic ZATCA), Authentication, Basic Accounting, Basic Parts & Inventory, Basic Reports, Basic Administration.

**Not included**: AI Platform, CRM & Marketing, Call Center, Team & HR, Customer App portal, API access, advanced ZATCA (credit/debit notes), custom reports.

### 3.2 Professional (SAR 2,499/month)

**Target**: Multi-branch workshops seeking comprehensive operations management with ZATCA compliance and AI capabilities.

| Parameter              | Value                                              |
|------------------------|----------------------------------------------------|
| Monthly Subscription   | SAR 2,499                                          |
| Annual Subscription    | SAR 25,490 (save SAR 4,498)                        |
| Branches               | Up to 3                                            |
| Named Users            | Up to 50                                           |
| Storage                | 50 GB (documents, photos, attachments)             |
| Support                | Email + phone, 4-hour response SLA                 |
| SLA                    | 99.9% uptime                                      |
| Data Backup            | Daily, 30-day retention                            |
| Updates                | Included, automatic deployment                     |

**Included modules**: All 13 domains with full access. Full ZATCA Phase 2 (standard + simplified invoices, credit/debit notes). AI Platform (Assistant, Knowledge Base, Agents, Smart Scheduling). Customer App portal. Read-only API access.

**Most popular tier**: The Professional tier covers the needs of the majority of multi-branch workshop groups and provides the best value per branch.

### 3.3 Enterprise (Custom Pricing)

**Target**: Large franchise groups, fleet maintenance operators, and organizations with 4+ branches or specialized requirements.

| Parameter              | Value                                              |
|------------------------|----------------------------------------------------|
| Monthly Subscription   | Custom (contact sales)                             |
| Branches               | Unlimited                                          |
| Named Users            | Unlimited                                          |
| Storage                | Custom allocation                                  |
| Support                | Dedicated account manager, 1-hour response SLA     |
| SLA                    | 99.95% uptime with SLA credits                     |
| Data Backup            | Real-time replication, 90-day retention             |
| Updates                | Included, scheduled deployment windows             |

**Included modules**: All 13 domains with full access. Full API access (read/write). Custom integrations. Dedicated infrastructure option. Priority feature requests.

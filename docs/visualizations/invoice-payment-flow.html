ZATCA Phase 2 Requirements Summary

Fatoora e-invoicing compliance requirements for clearance model

Requirement Status Implementation Details
UBL 2.1 XML Format Mandatory XML generation engine with UBL schema validation All invoices generated as XML following ZATCA UBL 2.1 specification
Digital Signature Mandatory X.509 certificate from ZATCA-approved CSP XMLDSig with SHA-256, certificate stored in HSM or secure key vault
QR Code (TLV) Mandatory Tag-Length-Value encoding, Base64 in QR 5 mandatory fields: seller, VAT#, timestamp, total w/VAT, VAT amount
Hash Chain Mandatory SHA-256 hash of previous invoice stored in current Prevents tampering and ensures sequential integrity of invoice ledger
UUID per Invoice Mandatory UUIDv4 generated at creation Globally unique identifier, immutable after ZATCA submission
Clearance Model Mandatory Real-time API submission to ZATCA Standard invoices (B2B) require clearance before issuance to buyer
Credit/Debit Notes Mandatory Reference original invoice UUID Must link back to original cleared invoice, same XML + signing flow
Bilingual Display Recommended EN/AR dual-language invoice rendering Arabic mandatory for local tax invoices; English for export or bilingual

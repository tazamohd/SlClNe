Integration Details

SALIS AUTO uses a hub-and-spoke integration model. The platform hub orchestrates all external communications via RESTful APIs, webhooks, and SOAP endpoints.

ZATCA Compliance

Mandatory e-invoicing with XML generation, QR codes, digital certificates, and real-time validation against ZATCA Phase 2

Payment Processing

Stripe integration handles card payments, refunds, recurring billing, and webhook-based status updates

Communication Stack

SMS for OTP and alerts, email for transactional and marketing, WhatsApp Business API planned for service updates

Future: OBD/Telematics

Planned vehicle diagnostics integration via OBD-II ports for automated fault code reading and fleet telemetry

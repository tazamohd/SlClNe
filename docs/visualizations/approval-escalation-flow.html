SAR 0
Move the slider to begin

Escalation Rules

Financial approvals escalate up the chain until reaching a role with sufficient SAR ceiling. Requests exceeding all role limits require Owner/SuperAdmin authorization.

7 Approval Tiers

From SAR 5,000 (Advisor) to unlimited (Owner), each tier represents increasing financial authority

Automatic Escalation

When a request exceeds a role's ceiling, it automatically routes to the next tier in the approval chain

Audit Trail

Every approval/rejection is logged with timestamp, role, user ID, and SAR amount for compliance

Branch Scoping

Approval authority is scoped per branch for Manager and below; Owner/SuperAdmin approve cross-branch

Infrastructure Details

SALIS AUTO runs on a cloud-native architecture with horizontal scaling, read replicas for reporting, and a defense-in-depth security model across three network zones.

Auto-Scaling

API and SPA tiers scale 2-8 containers based on CPU and request latency. Scale-in cooldown prevents flapping.

Database HA

PostgreSQL streaming replication with automatic failover. Read replica offloads reporting and analytics queries.

Security Zones

Three-tier network: DMZ for public traffic, private subnet for application logic, isolated subnet for data stores.

Zero-Downtime Deploy

Rolling deployments with health-check gates. Blue-green strategy for database migrations with backward compatibility.

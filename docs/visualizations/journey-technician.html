SA-VIZ-010

Technician User Journey

Workshop repair workflow from job acceptance through QC handoff, with Segregation of Duties enforcement.

Segregation of Duties Enforcement

The technician who performs a repair is blocked from conducting Quality Control on the same job. The system enforces this at the role level. Additionally, technicians have a SAR 0 approval ceiling -- they cannot approve any financial transactions, including their own parts requests.

Workflow Breakdown

1

Authentication & Queue

Technician logs in with workshop credentials. Dashboard shows assigned jobs sorted by priority. Each card displays vehicle info, service type, and estimated duration. Overdue jobs are flagged in red.

2

Job Acceptance & Details

Accept the job to lock it in. View full details: customer contact, vehicle plate and VIN, mileage, service history, inspection photos from the service advisor, and the specific work requested.

3

Parts Request (SOD)

Request required parts from inventory. The technician cannot approve this request (SAR 0 ceiling). A Parts Manager or Service Advisor with a higher approval ceiling must authorize the release. This is a core SOD control.

4

Repair Execution

Perform the repair. Update job status to In Progress. Log time spent with start/stop timer. Add detailed technician notes describing work done. Capture before/after photos as evidence.

5

QC Handoff (SOD)

Mark repair complete. Job moves to QC queue automatically. The system enforces that a different person must perform quality control. If QC fails, the technician receives rework notes.

6

Next Job Cycle

After QC handoff, return to the job queue to accept the next assignment. Performance metrics (jobs/day, rework rate, avg time per job) are tracked and visible to the Branch Manager.

Technician Role Boundaries

Capability Allowed Blocked
View assigned jobs Yes --
Update repair status Yes --
Request parts Yes --
Approve parts request -- SAR 0
Perform QC on own repair -- SOD
View financial data -- No access

Job Queue Management

Technicians see only jobs assigned to them by the Service Advisor. Jobs are prioritized by urgency and estimated completion time. Real-time status updates visible to all stakeholders.

Parts Request Workflow

Technicians can request parts from inventory but cannot approve the request (SAR 0 ceiling). A Parts Manager or Service Advisor with appropriate approval limits must authorize the release.

Time & Photo Logging

All repair work is time-tracked. Technicians capture before/after photos and add detailed notes. This documentation supports quality assurance and customer transparency.

QC Handoff Protocol

Upon completing repairs, the job automatically enters the QC queue and is assigned to a different inspector. The technician receives notification when QC passes or if rework is needed.

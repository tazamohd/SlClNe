Authentication & Session Flow

Complete lifecycle from login through JWT issuance, token refresh, session expiry, OTP verification, 2FA, SSO, and password reset.

Login Flow The primary authentication path: credentials to JWT to dashboard.

Security Architecture

SALIS AUTO implements defense-in-depth for authentication and session management, following OWASP best practices adapted for the Saudi Arabian automotive market.

httpOnly Cookies

Tokens never touch JavaScript. Stored as httpOnly, Secure, SameSite=Strict cookies. Immune to XSS token theft.

Token Rotation

Each refresh issues a new token pair and invalidates the old family. Reuse of an old refresh token revokes the entire chain.

Rate Limiting

Login: 5 attempts / 15 min per IP. OTP: 3 attempts per code. Password reset: 3 emails / hour. Prevents brute-force attacks.

2FA / TOTP

Optional time-based one-time passwords with 8 backup codes. 30-second window with +/-1 step tolerance for clock drift.

Session Invalidation

Password changes revoke all sessions. Admin can force-logout any user. Token family tracking detects replay attacks.

Bilingual Support

All auth screens render in both English and Arabic (RTL). OTP SMS messages sent in the user's preferred language.

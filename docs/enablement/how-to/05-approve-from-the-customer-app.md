# 05 · Approve an estimate from the customer app / اعتماد عرض السعر من تطبيق العميل

**Goal.** The customer authorises the work from their phone with a one-time code and a signature.
**Role.** Customer, guided by the service advisor. **Time.** 1 minute.
**Before you start.** The estimate was sent (how-to 04). The SMS provider is connected, or the advisor reads the code from the Customer Approval screen in demo.

**Steps**
1. The customer opens the **Secure link** from the SMS, or the **Approve estimate** tile in the customer app.
2. The screen shows **Summary**, **What we found**, **Labour** and the total. "The work your advisor recommends, with the reason for each."
3. **One-time code verification**: "Enter the one-time code we send you to sign off this estimate." The screen shows "Code sent to" the phone.
4. Enter the **One-time code**, then sign under **Authorise the work**.
5. The screen reads **Captured e-signature** then **Signed and authorised**. The job moves to Repair.

**Done when.** Workshop → Customer Approval shows **Signed and authorised** with **Linked estimate approval**.
**If it fails.** "The code did not match.": re-enter; request a new code. "SMS not connected" / "Not connected": the provider is not configured (KB `setup-integrations.md` §SMS); in demo the advisor reads the code on screen. "Nothing to approve": the estimate was already decided.

**الهدف.** يعتمد العميل العمل من هاتفه برمز لمرة واحدة وتوقيع.
**الدور.** العميل بإرشاد مستشار الخدمة. **الوقت.** دقيقة.
**قبل البدء.** أُرسل العرض (دليل 04). مزوّد الرسائل متصل، أو يقرأ المستشار الرمز من شاشة اعتماد العميل في العرض التجريبي.

**الخطوات**
1. يفتح العميل **الرابط الآمن** من الرسالة، أو بطاقة **اعتماد عرض السعر** في التطبيق.
2. تعرض الشاشة **الملخص** و**ما وجدناه** و**الأجرة** والإجمالي.
3. **التحقق بالرمز لمرة واحدة**: «أدخل الرمز الذي نرسله إليك لاعتماد هذا العرض».
4. أدخل **الرمز لمرة واحدة** ثم وقّع تحت **اعتمد العمل**.
5. تقرأ الشاشة **التُقط التوقيع الإلكتروني** ثم **موقَّع ومعتمَد**. ينتقل العمل إلى الإصلاح.

**تكتمل حين** تعرض شاشة اعتماد العميل **موقَّع ومعتمَد**.
**إن فشلت.** «الرمز غير مطابق»: أعد الإدخال أو اطلب رمزاً جديداً. «الرسائل النصية غير متصلة»: المزوّد غير مهيأ؛ في العرض التجريبي يقرأ المستشار الرمز من الشاشة. «لا شيء للاعتماد»: بُتّ في العرض أصلاً.

**كتلة الوسائط**
- مقطع قصير (A5 ثم T5، هاتف 390). الخطاف: «توقيع من الهاتف. في العصر نفسه». اللقطات: ١ «ما وجدناه، مع السبب» / ٢ «رمز لمرة واحدة» / ٣ «موقَّع ومعتمَد. يبدأ الإصلاح». التعليق: «اعتماد عرض السعر من ٤٨ ساعة على الورق إلى ٤ ساعات بتوقيع الهاتف. الأساس: التوقيع عند الكاونتر». الطلب: **احجز عرضاً**.
- مجموعة الصور: شاشة الاعتماد؛ إدخال الرمز؛ **موقَّع ومعتمَد** (390).

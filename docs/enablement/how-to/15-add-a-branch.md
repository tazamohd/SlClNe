# 15 · Add a branch / إضافة فرع

Long-form: `docs/knowledge-base/how-to/configure-branches.md`. This file is the media companion: exact labels as the screen shows them, and the media block.

**Label check against the KB.** The KB gives the route as `/admin/branches`; the app's route is `/branches` under Administration → Branches. The KB explains scoping with database column names; on camera say only "branch-scoped users see their branch". The button is **Add Branch**; the search field reads **Search branches...**.

**Goal.** Create a location so users and job cards can belong to it.
**Role.** Owner or super admin (create and edit); branch manager can view. **Time.** 2 minutes.
**Before you start.** Know the branch name in both languages and its city.

**Steps**
1. Administration → Branches. Read the list: name, city, main branch, status, **Monthly Revenue**.
2. **Add Branch**. Fill the English and Arabic names, the city, and whether it is the main branch.
3. Save. The branch appears in the list and is selectable on users and job cards.
4. **Search branches** to confirm.

**Done when.** The new branch is in the list and a new job card can be opened on it.
**If it fails.** "No branches found" / "No branches match the current search.": clear the search. "Loading branches..." that never ends: the API is not reachable; quote the request id.

**Media block**
- Short, T5. Hook: "One more branch, one more line on the board." Beats: 1 "Add Branch, both names" / 2 "City, main or not" / 3 "Job cards open on it today." VO: "Every branch writes to the same ledger and the same audit trail." CTA: **Book a demo**.

الدليل المطوّل: `docs/knowledge-base/how-to/configure-branches.md`. هذا الملف رفيقه للوسائط: نص الأزرار كما تعرضه الشاشة وكتلة الوسائط.

**الهدف.** إنشاء موقع لينتمي إليه المستخدمون وبطاقات العمل.
**الدور.** المالك أو المشرف العام؛ مدير الفرع يعرض فقط. **الوقت.** دقيقتان.

**الخطوات**
1. الإدارة ← الفروع. اقرأ القائمة: الاسم، المدينة، الفرع الرئيسي، الحالة، **الإيراد الشهري**.
2. **إضافة فرع**. املأ الاسم بالعربية والإنجليزية والمدينة وهل هو الفرع الرئيسي.
3. احفظ. يظهر الفرع في القائمة ويُختار في المستخدمين وبطاقات العمل.
4. **ابحث في الفروع** للتأكد.

**تكتمل حين** يكون الفرع في القائمة ويمكن فتح بطاقة عمل عليه.
**إن فشلت.** «لا فروع» / «لا فروع تطابق البحث»: امسح البحث. «جارٍ تحميل الفروع...» بلا نهاية: الواجهة غير متاحة؛ اذكر معرّف الطلب.

**كتلة الوسائط**
- مقطع قصير (T5). الخطاف: «فرع جديد، سطر جديد على اللوحة». اللقطات: ١ «إضافة فرع بالاسمين» / ٢ «المدينة، رئيسي أم لا» / ٣ «بطاقات العمل تُفتح عليه اليوم». التعليق: «كل فرع يكتب في الدفتر نفسه وسجل التدقيق نفسه». الطلب: **احجز عرضاً**.
- مجموعة الصور: قائمة الفروع؛ نموذج الإضافة بالاسم العربي؛ الفرع في بطاقة عمل جديدة.

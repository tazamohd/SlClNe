## Combination Rules

1. Never pair Bold Studio (T3) with Swiss Rational typography (F6) -- conflicting personalities
2. Deep Dark (T2) works best with Cinematic Centered (H1) or Typography Behemoth (H4)
3. Warm Neutral (T4) pairs naturally with Editorial Serif+Sans (F4) or Polished Grotesk (F2)
4. Stacked Poster rhythm (S3) requires MOTION >= 5 to avoid feeling static
5. Bento Grid (S2) requires DENSITY >= 4 to justify the grid structure
6. Typography Behemoth hero (H4) should use Compressed (F5) or Space Grotesk (F3)

SALIS AUTO -- Certification Framework

1. Purpose

This document defines the SALIS AUTO certification framework, including tier requirements, assessment criteria, validity periods, recertification processes, and digital badge issuance. The framework ensures all platform users achieve and maintain a verified level of proficiency.

2. Certification Tiers

2.1 Tier Overview

TierMinimum ScoreBadge ColorTrainer EligibleDescription
Bronze70%BronzeNoCompetent user -- meets baseline
Silver80%SilverNoProficient user -- above average
Gold90%GoldYesExpert user -- eligible to train

2.2 Tier Details

Bronze Certification
  • Minimum Assessment Score: 70% across all course modules
  • Requirements:
  • Complete all modules in the assigned course
  • Pass the final assessment with 70% or higher
  • Complete all hands-on labs (attendance verified by trainer)
  • Privileges:
  • Full platform access for the assigned role
  • Listed as "Certified" in the staff directory
  • 12-month validity
Silver Certification
  • Minimum Assessment Score: 80% across all course modules
  • Requirements:
  • Meet all Bronze requirements
  • Score 80% or higher on the final assessment
  • Complete at least one cross-functional lab (e.g., advisor completes a finance lab)
  • Privileges:
  • All Bronze privileges
  • Eligible for cross-training in adjacent roles
  • Priority consideration for role advancement
  • 12-month validity
Gold Certification
  • Minimum Assessment Score: 90% across all course modules
  • Requirements:
  • Meet all Silver requirements
  • Score 90% or higher on the final assessment
  • Complete the Train-the-Trainer module (SA-TRN-012)
  • Pass the trainer qualification assessment
  • Demonstrate bilingual delivery capability (EN/AR)
  • Privileges:
  • All Silver privileges
  • Eligible to deliver training sessions as a certified trainer
  • Mentor new hires during onboarding
  • Participate in content review and course updates
  • 12-month validity

4. Assessment Process

4.1 Assessment Structure

ParameterValue
FormatMultiple-choice (4 options per question)
Questions per assessment30 (drawn from the Assessment Bank SA-TRN-013)
Time limit45 minutes
Question randomizationYes (order and options randomized per attempt)
Maximum attempts3
Cooldown between attempts48 hours
Accommodation+50% time for non-native language test takers

4.2 Scoring Methodology

  • Each correct answer scores 1 point
  • No negative marking for incorrect answers
  • Final score = (correct answers / total questions) x 100%
  • The highest score across all attempts determines the certification tier

4.3 Assessment Administration

MethodApplicable TracksProctor Required
In-personExecutive, OperationsYes
Online (LMS)Back-Office, ExternalNo (honor system)
Proctored onlineAny (on request)Yes (remote)

4.4 Remediation

If a participant fails to achieve Bronze (70%) after 3 attempts:

  1. Mandatory review session with a certified trainer (2 hours)
  2. Identify knowledge gaps using the per-domain score breakdown
  3. Complete targeted remediation modules for weak domains
  4. 7-day waiting period before a new assessment cycle (3 more attempts)
  5. If still unsuccessful, escalate to HR Manager and Training Coordinator

5.2 Recertification Process

5.3 Recertification Triggers

Beyond the annual cycle, recertification may be triggered by:

TriggerAction Required
Major platform update (new modules)Targeted refresher + assessment
Role change (e.g., advisor to manager)Complete the new role's course
ZATCA regulation changeFinance module refresher
SOD policy updateAdmin/security module refresher
Extended leave (90+ days)Refresher assessment upon return

5.4 Certification Revocation

Certifications may be revoked under the following circumstances:

CircumstanceAction
Repeated SOD violationsImmediate revocation; retraining
Security policy breachRevocation pending investigation
Employment terminationAutomatic revocation
Fraud or exam integrity violationPermanent ban from certification

8.3 Change Management

Changes to the certification framework require:

  1. Written proposal from the Training Coordinator
  2. Review by HR Manager and Super Admin
  3. Approval by the Owner/CEO
  4. 30-day notice to all certified staff before implementation
  5. Updated documentation published to the LMS
